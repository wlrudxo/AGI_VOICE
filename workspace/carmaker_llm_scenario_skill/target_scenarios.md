# Target Scenario Validation Set

Created: 2026-05-12

## Goal

Use a small set of reference CarMaker scenarios as pass/fail targets for the LLM scenario generation workflow.

Validation loop:

```text
target scenario
  -> generate IR
  -> emit OpenDRIVE/OpenSCENARIO 1.2
  -> osc2cm conversion
  -> postprocess only when necessary
  -> compare generated CarMaker TestRun/Road/Traffic outputs against reference
  -> document gaps
  -> improve source generation first, postprocessor second
```

Preference order for fixes:

1. Fix the generated IR / `.xosc` / `.xodr`.
2. Use supported `osc2cm` options correctly.
3. Add deterministic postprocessing only for converter gaps that cannot be solved cleanly in source generation.

## Comparison Method

Do not compare generated files by raw text equality.

Compare structured features:

- road file exists and loads
- ego vehicle infofile
- ego start position type and reference
- ego route/path/maneuver count
- traffic object count
- traffic object classes/templates
- each actor's start position type
- each moving actor's maneuver count
- action types: `VelControl`, `VelTransition`, `LaneChange`, `FollowTraj`, `RoutingChange`, `auto`
- trigger conditions
- converter warnings
- CarMaker runtime start result
- actor behavior observed in runtime, when visually/manual checked

## Tooling

Structured TestRun summary:

```bash
python3 workspace/carmaker_llm_scenario_skill/scripts/extract_testrun_summary.py \
  <testrun> \
  --json-out <summary.json> \
  --md-out <summary.md>
```

Structured comparison:

```bash
python3 workspace/carmaker_llm_scenario_skill/scripts/compare_testrun_summary.py \
  <reference_summary.json> \
  <candidate_summary.json> \
  --json-out <comparison.json> \
  --md-out <comparison.md>
```

The first comparison gate is intentionally structural, not raw text equality.
It checks road identity, ego routing/start/maneuver count, traffic count,
traffic start-type distribution, actor classes, maneuver dynamics, and actor
signature sequence. Runtime CarMaker start and visual behavior checks remain
separate gates.
