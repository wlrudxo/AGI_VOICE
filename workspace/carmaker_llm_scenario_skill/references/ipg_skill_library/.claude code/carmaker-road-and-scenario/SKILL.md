# CarMaker Road and Scenario

road와 scenario 관련 질문을 세 갈래로 분해하는 skill이다.

## Usage

1. `references/overview.md`를 먼저 읽는다.
2. 질문이 아래 무엇인지 구분한다.
   - Scenario Editor GUI workflow
   - OpenSCENARIO schema compatibility
   - IPGRoad API/code automation

## Working style

- 세 갈래를 섞지 말고 먼저 분리한다.
- GUI형이면 Quick Start에서 시작한다.
- schema형이면 버전과 ego/traffic 분리를 먼저 확인한다.
- code형이면 `IPGRoadAPI` examples/class reference 쪽으로 넘긴다.
