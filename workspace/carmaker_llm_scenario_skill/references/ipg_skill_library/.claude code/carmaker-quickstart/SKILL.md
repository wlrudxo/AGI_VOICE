# CarMaker Quickstart

CarMaker 입문과 GUI workflow 정리에 쓰는 skill이다.

## Usage

1. `references/overview.md`를 먼저 읽는다.
2. 질문이 아래 어디에 속하는지 분류한다.
   - first TestRun
   - vehicle dynamics
   - ADAS
   - powertrain
   - Scenario Editor
   - CM4SL entry
3. 섹션을 고른 다음 필요한 다음 문서를 제시한다.

## Working style

- 먼저 어느 Quick Start 섹션을 볼지 지정한다.
- 그 다음 GUI 기준 순서를 짧게 정리한다.
- deeper API 질문이면 다른 source나 skill로 넘긴다.
