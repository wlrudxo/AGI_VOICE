## 제품별 한 줄 요약

- CarMaker: 시뮬레이션 중심 제품. 대부분의 질문 출발점.
- IPGControl: quantity/diagram/analyze/export 중심 후처리 도구.
- Movie NX: 3D scene/render/Python scripting 도구.
- Instrument Designer: simulation dashboard와 custom component 도구.
- IPGGraph: GDL/tutorial 기반 plotting reference 성격.
