# CarMaker Quickstart

CarMaker를 처음 잡거나 GUI 기준 workflow를 정리할 때 쓰는 skill이다.

## 먼저 할 일

1. `references/overview.md`를 먼저 읽는다.
2. 질문이 아래 어디에 속하는지 고른다.
   - first TestRun
   - vehicle dynamics
   - ADAS
   - powertrain
   - Scenario Editor
   - CM4SL entry

## 기본 답변 방식

- 먼저 어느 Quick Start 섹션을 볼지 제시한다.
- 그 다음 GUI 기준 순서를 짧게 정리한다.
- 구현/자동화 질문이면 다음 문서나 다른 skill로 넘긴다.

## Representative prompts

- “CarMaker를 처음 쓰는데 어디서 시작하지?”
- “첫 TestRun 만드는 순서를 정리해 달라”
- “Scenario Editor는 Quick Start에서 어디를 보면 되지?”
