# IPG Visualization and Postprocess

시각화, 후처리, 대시보드, 렌더링 도구를 구분하는 skill이다.

## Usage

1. `references/overview.md`를 먼저 읽는다.
2. 원하는 결과물을 먼저 고른다.
   - signal diagram / analysis
   - 3D scene / render / annotation
   - operator dashboard / custom component
   - GDL tutorial / plotting asset

## Tool selection

- signal analysis -> `IPGControl`
- 3D scene/render -> `Movie NX`
- dashboard and controls -> `Instrument Designer`
- tutorial plotting asset -> `IPGGraph`
